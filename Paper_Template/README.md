# User supplied ACM template reference

`Association_for_Computing_Machinery__ACM____Small_Standard_Format_Template.pdf`
is a byte-for-byte copy of the PDF supplied in the workspace's sibling
`Paper_Template` folder on 18 November 2026. The original has not been moved.

The 10-page reference records `acmart` 2.19, TeX Live 2026/pdfTeX, the ACM small
journal page size (486 × 720 points), and sample `anonymous,review` settings.
Its sample author names, title, CCS text, J. ACM designation, DOI and publication
metadata are demonstrations and must not be copied as this paper's metadata.
The TRETS guide asks for author names and affiliations; anonymity must follow
the actual submission instructions, not be inferred from the sample.

The working source is [paper/latex/main.tex](../paper/latex/main.tex), using the
standard `acmart` class and `TRETS` journal identifier. Local compiler/class
versions are recorded separately from this reference. No custom replacement
class or PDF-to-LaTeX imitation of ACM styling is used.

- Journal guide: <https://trets.cse.sc.edu/tretsauthors.php>
- Standard ACM class: <https://ctan.org/pkg/acmart>
- Class maintainer documentation: <https://github.com/borisveytsman/acmart>
